# Programming Mastery

## Vision

Programming Mastery is a modern learning platform designed to help developers master programming through structured roadmaps, interactive challenges, projects, revision systems, and progress tracking.

---

## Objectives

- Teach programming effectively.
- Build a production-grade learning platform.
- Maintain high code quality.
- Create a scalable architecture.

---

## Tech Stack

Frontend:

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

Backend:

- Express.js

Database:

- PostgreSQL
- Prisma

Monorepo:

- Turborepo

---

## Development Principles

- Build one feature at a time.
- Keep the application production-ready.
- Write reusable components.
- Prefer simplicity.
- Document major architectural decisions.
